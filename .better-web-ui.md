# Hayagreeva Energy — Design Context

## Target audience
- Thermal / mechanical / packaging engineers at OEMs and hyperscalers
- Data-center infrastructure and facility engineers
- Technical executives evaluating liquid-cooling roadmaps
- Investors and partners assessing deep-tech credibility

## Use cases
- Understand what Hayagreeva HEx is within seconds
- Grasp package-level thermal performance (5,000+ W, 0.005 °C/W, copper matrix)
- Follow chip → HEx → CDU → facility heat path
- Request a pilot / engineering evaluation

## Brand personality
Precision · thermal engineering · metal · fluid · industrial scale · technical honesty.
Not SaaS, not AI-startup purple, not cyberpunk, not generic Webflow.

## Visual direction
Graphite + warm paper + copper (material) + restrained heat orange + muted coolant teal.
Typography: Space Grotesk (display) + IBM Plex Sans (body) + IBM Plex Mono (metrics).
Product storytelling via engineering schematics when photography of HEx is unavailable — always labeled as conceptual.

## Verified claims only
- 5,000+ W continuous package heat removal
- 0.005 °C/W rated thermal resistance
- 4,000+ m²/m³ wetted surface area
- ~25 °C implied ΔT at rated conditions
- Copper-matrix architecture
- NVIDIA / AMD / Intel package-specific compatibility
- 14 patent filings
- Launch May 28, 2026
- Pilot evaluation with qualified partners

## Stack
Static multi-page HTML + CSS + vanilla JS on GitHub Pages. No React, no shadcn.
